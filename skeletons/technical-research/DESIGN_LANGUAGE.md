# DESIGN LANGUAGE - TECHNICAL / RESEARCH

## Character
Systematic, analytical, information-rich, precise.

## Principles
- Make structure visible.
- Use metadata as design material.
- Let diagrams, numbers and labels establish identity.
- Use hierarchy to manage density.
- Prefer systems over decoration.

## Directions
- modular grid;
- numbered projects;
- metadata rail;
- YEAR / TYPE / ROLE / TOOL labels;
- fine divider lines;
- consistent project-description structure.

## Distinctive move ideas
Choose one:
- persistent metadata rail;
- numbered coordinate grid;
- project data labels;
- research-paper-like references;
- system-status footer with real information.

## Avoid
- fake terminal styling;
- meaningless metrics;
- decorative charts;
- cyberpunk clichés.

## Success test
The site should feel **structured and intelligent**, not "tech-themed."
