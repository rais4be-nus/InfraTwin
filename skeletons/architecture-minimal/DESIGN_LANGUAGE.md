# DESIGN LANGUAGE - ARCHITECTURE / MINIMAL

## Character
Quiet, spatial, image-led, precise.

## Principles
- Let project imagery dominate.
- Reduce interface chrome.
- Use generous margins.
- Keep typography restrained.
- Treat empty space as active.
- Use project ordering/indexing to create rhythm.

## Directions
- large image fields;
- strong edge alignment;
- numbered projects;
- sparse navigation;
- occasional full-width image;
- narrow captions.

## Distinctive move ideas
Choose one:
- persistent project index;
- project numbers as navigation;
- drawing-sheet margin system;
- captions like architectural annotations;
- one oversized full-bleed interruption.

## Avoid
- card grids;
- shadows;
- rounded UI containers;
- decorative icons;
- unnecessary gradients;
- excessive animation.

## Success test
The site should feel **spatial and authored**, not empty.
