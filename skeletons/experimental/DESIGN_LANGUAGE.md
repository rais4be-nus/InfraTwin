# DESIGN LANGUAGE - EXPERIMENTAL

## Character
Unexpected, expressive, rule-breaking with control.

## Principles
- Break a convention deliberately.
- Keep enough consistency to remain usable.
- One strong idea is better than ten effects.
- Use interaction as part of the concept.
- Preserve readability and mobile fallback.

## Directions
Possible:
- off-grid composition;
- unusual navigation placement;
- deliberate overlap;
- giant typography;
- asymmetric images;
- non-standard project index.

## Interaction
Choose at most 1-2:
- unusual hover;
- draggable element;
- horizontal project rail;
- scroll-linked reveal;
- cursor behaviour;
- typographic pointer response.

## Avoid
- random motion;
- every element animated;
- unreadable body text;
- interaction that blocks content;
- novelty without hierarchy.

## Success test
A visitor should be able to explain the **one main idea** behind the site.
