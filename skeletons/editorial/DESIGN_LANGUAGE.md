# DESIGN LANGUAGE - EDITORIAL

## Character
Typographic, composed, intentional, publication-like.

## Principles
- Let typography carry identity.
- Use strong differences in scale.
- Prefer asymmetric but controlled layouts.
- Use whitespace as structure.
- Treat captions, dates and metadata as part of the composition.
- Let images reinforce or interrupt the editorial rhythm.

## Directions
- conceptual multi-column grid;
- large display title;
- narrow metadata column;
- alternating project alignments;
- varied section rhythms.

## Distinctive move ideas
Choose one:
- oversized project number;
- folio/page-number language;
- vertical caption;
- title crossing multiple grid columns;
- one image breaking a grid boundary.

## Avoid
- fake newspaper styling;
- card-based sections;
- decorative gradients;
- excessive motion.

## Success test
The page should feel **composed**, not merely styled.
