# AI SLOP CHECKLIST — INFRATWIN

Before publishing, check the following.

## Generic patterns
- [ ] The page does not begin with generic hero copy ("Revolutionizing..." /
      "The future of...") unless the deck itself uses language that strong.
- [ ] There is no decorative gradient without a reason.
- [ ] There is no generic row of 3-4 rounded feature cards.
- [ ] Glassmorphism is not being used simply because it "looks modern."
- [ ] Pills/tags are not everywhere.
- [ ] Not every section is centred.
- [ ] There are no generic icons beside every heading.
- [ ] There are no meaningless progress bars or invented percentages.
- [ ] There are no testimonials, logos, or claims not present in the source decks.
- [ ] Animations have a design purpose.
- [ ] Sections do not all use exactly the same rhythm.
- [ ] The page does not accidentally look like a generic SaaS landing page —
      distinguish a *pitch* from a *product marketing site*.

## Content fidelity
- [ ] Every claim, number, and feature traces back to `InfraTwin.pptx` or
      `Infrastructure Copilot.pptx` — nothing invented to fill a gap.
- [ ] Sections flagged as "missing/thin" in `DESIGN.md` were actually
      flagged to the project owner, not silently filled in.
- [ ] The video embed uses the real YouTube URL, not a placeholder left in
      by accident.

## Reference fidelity
- [ ] I can point to a specific reference behind the typography.
- [ ] I can point to a specific reference behind the composition.
- [ ] The distinctive design move is visible.
- [ ] The visual direction is distinct from the personal-portfolio
      project's own aesthetic, not a reskin of it.

## Identity
- [ ] The page reflects InfraTwin's actual content and structure, not a
      generic startup-pitch template.
- [ ] The first screen feels specific to this product, not swappable.
- [ ] The hierarchy fits a pitch being evaluated, not a marketing funnel.

## Final test

> **Could I swap InfraTwin's name, product, and figures for another
> startup's and nobody watching the symposium would notice?**

- [ ] NO — the page is specific to InfraTwin.

If YES: revise.
