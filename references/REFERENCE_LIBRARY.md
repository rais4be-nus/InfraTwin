# BASE REFERENCE LIBRARY — INFRATWIN

Starting point. Find at least one reference yourself and add it (with
what specifically to follow / not copy) to `DESIGN.md` before building.

## Startup pitch / single-narrative product pages
Look for a confident, evidence-led narrative arc (problem → solution →
proof → ask), restrained motion, and imagery that carries real product
substance rather than stock photography.

Search terms:
- YC startup one-pager
- seed-stage pitch page
- deep-tech / robotics startup landing page
- product launch page architecture

Discovery:
- Y Combinator company pages — https://www.ycombinator.com/companies
- Products at Stripe, Linear (for restraint/typography, not literal style)

## Editorial / Typographic
Oversized typography, asymmetric layouts, strong text/image hierarchy,
deliberate whitespace, readable grids.

Discovery: Awwwards, SiteInspire, Minimal Gallery

## Architecture / Minimal
Large project imagery, sparse navigation, restrained typography, careful
cropping, generous margins.

Discovery: Awwwards, SiteInspire, Land-book

## Technical / Research
Visible grids, metadata, numbering, monospace accents, diagrams/data,
systematic hierarchy. (Note: the personal-portfolio project already used
this language — if InfraTwin also lands here, the specific typographic/
colour choices must still read as distinct, not a reskin.)

Discovery: Awwwards, Godly, SiteInspire

## Experimental / Brutalist
Unconventional navigation, raw typography, exposed structure, one strong
interaction concept.

Discovery: Brutalist Websites, Godly, Awwwards

## When you find a reference you like
Put it in `DESIGN.md` and answer:
1. Why do I like it?
2. What specifically do I want this page to follow?
3. What do I **not** want to copy?
