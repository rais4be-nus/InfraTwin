# InfraTwin

Startup pitch page for **InfraTwin** (RAIS4BE Lab, National University of
Singapore), built for the [Startup Architecture Symposium](https://startups.arch.ethz.ch/)
at ETH Zurich's "Startup Pitch" track.

Static site — plain HTML/CSS + minimal JS, no framework, no build step.
Publishes via GitHub Pages from this repo:
`https://github.com/rais4be-nus/InfraTwin` →
`https://rais4be-nus.github.io/InfraTwin/`

See `00_START_HERE.md` to begin, `DESIGN.md` for the project brief, and
`CODEX_PROMPTS.md` for the build sequence.
